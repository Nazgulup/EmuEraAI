# 剧情模板与可编辑函数清单

内置 ZIP 同时作为 Windows 嵌入资源和 Android 应用资源，包含 182 份函数元数据及匹配索引，没有游戏正文。完整配置游戏与补丁/脚本包区分处理；匹配关键词、版本、标识后，再核对具体函数内容指纹。重复模板可共用，冲突的修改版不会被猜测套用。

没有匹配模板时，本地后台扫描 ERB，按函数命名与脚本结构生成清单，保存到应用数据的 `ai/story-documents`。脚本只被读取，不执行额外语句。退出会取消后台扫描。

在“函数清单 / 编辑选择”中：

1. 搜索函数名或文件，或筛选明确日常、剧情、不确定。
2. 勾选表示手动优先 AI，取消表示保留原文；也可恢复自动模式。自动模式只允许明确日常。
3. 可编辑备注；保存后按游戏和脚本指纹记住。开启 AI 自动生成时，当前允许段落会直接生成，游戏数值不变。
4. 导出 JSON 可备份或编辑；通过“导入剧情规则模板”导入规则。导入会替换当前游戏的手动规则，建议先导出备份。备注用于本地整理，不作为 AI 提示词。

函数允许不覆盖剧情父调用或事件标记分支；明确禁止优先于临时允许。临时改写当前剧情可以用“仅本段允许”，下一次输入后失效。脚本改变后旧指纹不匹配，不能沿用旧许可。

日志 `story.template`、`story.document`、`story.document-edit` 和 `story.decision` 给出匹配、建立、编辑及生成判断原因。没有原口上时的补写也受同一规则约束。
