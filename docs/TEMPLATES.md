# AI 生成开关与函数清单

Windows 0.10 / Android 0.12 不再内置、读取或自动套用剧情模板。所有捕获到的有效口上默认允许 AI；日常/剧情/不确定分类只用于筛选。生成失败回退原口上，补写失败保留原画面。

新设置默认启用 AI 与自动生成；已有全局关闭偏好不被强制改写。请先配置 API。游戏脚本和数值始终由原解释器处理。

加载游戏后自动扫描 ERB 函数并建立清单，不执行脚本。进入“AI 口上 → 函数清单 / 编辑选择”，所有未手动关闭的项默认勾选。取消勾选、保存，即可关闭指定剧情/函数；重新勾选或恢复默认可开启。支持搜索、分类筛选、备注和每页 30 项。

“仅本段关闭 AI”只影响当前事件，下一次游戏输入后失效。“此函数关闭 AI”按游戏、相对文件路径和函数名持续保存，包含其父调用范围，同一函数更新脚本后仍关闭。明确的函数关闭优先于本段开启。恢复默认会清除同函数旧指纹记录。旧版已保存的手动关闭记录继续有效。

保存关闭会恢复原文、取消正在生成的请求并忽略迟到的回复；自动生成、重新生成与无原口上补写都遵守同一开关。开启后可重新生成，保存清单时若已开启自动生成，会直接更新当前段落，不重复结算数值。

使用“导出函数文档”或“导出函数开关”备份 JSON，再用“导入函数开关”恢复。导入会替换本游戏手动规则，备注只用于整理，不作为 AI 提示词。函数文档不包含游戏正文。

日志 `story.mode`、`story.document`、`story.document-edit`、`story.decision`、`story.override` 记录默认模式、函数来源与关闭原因。来源信息不完整不再自动拦截，可使用仅本段关闭；无法定位到的函数关闭记录无法用于该段。
