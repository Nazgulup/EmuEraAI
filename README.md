# ERA AI 加载器

基于 Emuera 的修改版，包含 Windows 加载器及 Android APK 源码。当前功能版本：Windows 0.10.2 / Android 0.12.2。

选择已有 ERA 游戏目录；Windows 也可选择原 exe 来定位目录，再由内置兼容引擎运行。游戏脚本、变量和存档由原解释器处理，AI 只负责显示文字。重新生成不重复执行游戏操作，失败时恢复原口上。

## 本次调整：无原口上时以角色台词为主

Windows 0.10.2 / Android 0.12.2 将无原口上补写的默认提示改为：以角色直接说出口的台词为主体，通常 1～3 句，使用对话引号，辅以少量动作或神态。菜单补写和空白口上按键等待、首次生成与重新生成都生效，无需重新导入酒馆预设。

- 已知自称、对玩家称呼仍使用游戏变量；未知时省略主语或称呼，自然说话，不擅自添加“我”“你”，也不因此只写旁白。
- 原文已有内容时继续参考原文视角。事实明确角色此刻无法说话时使用非语言反应；不替玩家发言、选择或推进事件。
- 日志 `dialogue.supplement-style` 记录补写采用台词为主的要求。这是生成提示，实际表达仍受模型、预设和角色状态影响；不会因台词风格另发自动重试或重复结算。
- 保留手动关闭、失败回退和重新生成不改变数值。测试使用中性台词与受控 API 回复，没有调用个人 API 或进行 Android 真机测试。

## 口上函数识别与空白口上

Windows 0.10.1 / Android 0.12.1 同步支持带前缀、数字后缀及更多常见口上函数命名。明确口上范围内的空 `PRINTFORMW` / `PRINTW` 按键等待也能自动生成，生成结果回填原位置；重新生成不执行脚本或提前改变变量。

- 空白口上等待与菜单补写分开处理，前者不需要开启菜单“无原口上时补写”；仍遵守全局 AI、自动生成和手动关闭开关。
- 失败恢复原文，原文为空时保持空白；每次新输入使用独立空口上事件，避免复用旧回复。
- 两端日志注明空文本等待和捕获函数。普通菜单、已清除的输出或离开口上范围的空白不会因此自动补写。
- 扫描报告是静态候选清单；已有上层口上调用、动态调用和分支条件会影响实际结果，不能将所有候选视为故障。

## 功能

- 可配置 AI API、模型列表和酒馆 Chat Completion 预设，支持大预设及条目选择。
- AI 正文回填游戏画面；保留已捕获的角色称呼；提供生成、回退和正文对比日志。
- 两端取消剧情模板与自动分类拦截，口上默认开启 AI。可手动关闭当前段落或指定剧情/函数；关闭后显示原文，AI 失败也回退原文。
- 所有游戏自动建立可编辑函数清单：默认勾选，可搜索、筛选、取消勾选关闭 AI、恢复默认、编辑备注、按游戏保存并导出 JSON。保存当前开启的函数后优先生成 AI；数值不重复结算。
- Android 提供横屏全屏、半透明悬浮选项、原行分组、无原口上补写及正文/选项翻译。补写同样遵守手动关闭记录，翻译保留选项原输入值。
- 日本文本编码兼容；退出游戏可回到选择界面。

电脑端入口：**AI 口上 → 剧情 / 函数开关 → 函数清单 / 编辑选择**。手机端在 AI 面板进入同名区域。

## 编译

Windows PowerShell，安装包构建依赖由项目脚本放在本地 `.tools`，不会写入游戏目录：

```powershell
.\setup-build.ps1
.\build.ps1 -Test
.\Start-Loader.cmd
```

Windows 输出 `dist/EmueraAI.exe`。不需要任何剧情模板文件。

Android 还需要 Node.js/npm；脚本按锁定版本安装 .NET SDK、MAUI Android、JDK 和 Android SDK：

```powershell
.\setup-android.ps1
.\build-android.ps1
```

Android 输出 `android-dist/ERA-AI-Loader.apk`。只构建 ARM64，最低 Android 7.0；具体分支兼容性需实际游戏验证。新源码构建会使用本地开发签名，请自行保留签名用于后续更新；本仓库不包含任何发布私钥。

详细说明：[构建与测试](docs/BUILD.md)、[生成开关与函数清单](docs/TEMPLATES.md)、[第三方说明](THIRD_PARTY_NOTICES.md)。

## 仓库内容

- `src/Emuera`：Windows 解释器和界面。
- `portable/Dialogue`：两端共用的 AI、手动开关和函数文档逻辑。
- `portable/era-core`：Android 内核、宿主、网页界面及必要构建文件，基于上游固定提交的修改版。
- `tests`、`portable/Tests`：中性测试夹具和回归测试；`demo` 是自建中性演示。

此源码目录可直接作为 GitHub 仓库根目录。编译产物由 `.gitignore` 排除，已编译的 exe/APK 可另行放在 Releases。本目录没有第三方游戏本体、个人存档、API 设置、聊天日志或签名私钥。
